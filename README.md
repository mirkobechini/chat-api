# Chat API

API REST Express per una chat: gestione di utenti, conversazioni e messaggi con operazioni CRUD complete (index, show, store, update, patch, destroy) su dati in memoria.

## Tecnologie

- Node.js
- Express 5
- JavaScript (CommonJS)

## Avvio

```bash
npm install
npm start
# oppure in sviluppo
npm run dev
```

Server su `http://localhost:3000`.
